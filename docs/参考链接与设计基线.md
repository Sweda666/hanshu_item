# 参考链接与设计基线

HanShu-Item 当前使用 Minecraft 26.1.2、Forge 64.1.3 和 Java 25，构建使用 ForgeGradle 7。
项目仓库为
[Sweda666/hanshu_item](https://github.com/Sweda666/hanshu_item)。

## 实现依据

| API | 当前用途 |
| --- | --- |
| `ItemStack` / `DataComponentPatch` | 保存和应用物品的原生组件补丁 |
| `DataComponentPatch.CODEC` / `NbtOps` | 在组件对象和 SNBT 之间转换，运行时使用注册表上下文 |
| `NbtPathArgument` | 解析同步排除路径，支持带引号的键名和列表下标 |
| Forge 事件总线 | 注册指令，处理玩家登录、容器打开、区块加载和 tick |

NBT 树编辑器布局曾参考 IBE Editor；当前功能以本仓库源码为准，没有运行时依赖该编辑器。
